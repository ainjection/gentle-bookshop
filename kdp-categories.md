# KDP categories, exact names (8 Sep 2026)

Every category below is copied from Amazon's live Books category tree today. KDP's category picker uses the same tree and the same wording.

HOW TO SET THEM (same for every book)
1. KDP Bookshelf > click the three dots next to the book > Edit details.
2. Scroll to Categories > Edit (or Choose categories).
3. Remove whatever is in there now.
4. In the search box type the LAST word of the category (for example "Coloring Books"). Pick the line whose full path matches the one below exactly. Some words appear in several places, so match the whole path.
5. Repeat until all 3 slots are filled. Save.
6. Save and Continue twice, then Publish on the Pricing page. Review takes up to 72 hours. Do not edit that book again until it clears.

Tip: Amazon's picker says "Books > " at the front of every path. I have left that off.
